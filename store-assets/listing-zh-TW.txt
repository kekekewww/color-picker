名稱
Color Picker

簡短說明
選取顏色代碼，立即看見色彩。支援 HEX、RGB、HSL 與現代 CSS 色彩格式。

詳細說明
Color Picker 幫助你在閱讀網頁或設計文件時，直接看懂文字中的顏色。

在一般網頁反白支援的 CSS 色碼，旁邊就會顯示對應色票。你可以一次選取多個顏色比較配色，點擊預覽複製代碼，或按 Esc 關閉。

安裝後請重新整理已開啟的網頁，再選取例如 #365DCC 的文字試用。也可以從工具列開啟內建練習場，依照範例操作。設定中可暫停預覽或關閉文字旁的小色塊。

選取內容、判斷邊界所需的相鄰字元與定位資訊只在裝置上處理，不上傳至開發者或第三方，也不建立選取紀錄。僅偏好設定會儲存在本機；點擊色票時才會寫入剪貼簿，不讀取剪貼簿內容。

需要 Chrome 111 以上。本功能適用於文字中的顏色代碼，不提供圖片取色。瀏覽器設定頁、Chrome 商店及內建 PDF 檢視器等受保護頁面無法使用，密碼欄位不會解析。本機 HTML 需自行開啟檔案網址存取；若瀏覽器限制直接複製，可複製原文中的色碼。
